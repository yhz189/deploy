# 香蕉面积分级离线验证

## 目的

该工具用于验证“YOLO 确认香蕉类别后，再用 OpenCV 估计香蕉可见面积”的可行性。

当前仅作为离线二阶段辅助实验：

- 不接入 `main.py` 的库存判断。
- 不修改 SQLite 数量。
- 不替代 YOLO 分类。
- 不表示已经实现通用图像分割。

## 数据来源

板端 `main.py` 每次完成事件分析后，会在以下目录保存最终变化区域的动作前后裁剪图：

```text
/root/2_deploy/debug_crops/event_时间_序号/
```

每个变化区域对应：

```text
final_01_ref.jpg
final_01_new.jpg
```

其中 `ref` 为动作前稳定帧裁剪图，`new` 为动作后稳定帧裁剪图。

## PC 端运行

先从板端复制一个事件目录：

```bash
scp -r root@192.168.3.100:/root/2_deploy/debug_crops/event_xxx .
```

运行离线评估：

```bash
python tools/evaluate_banana_area.py ^
  --before event_xxx/final_01_ref.jpg ^
  --after event_xxx/final_01_new.jpg ^
  --output-dir banana_area_output
```

如已有同尺寸空场景和满量香蕉校准图：

```bash
python tools/evaluate_banana_area.py ^
  --before event_xxx/final_01_ref.jpg ^
  --after event_xxx/final_01_new.jpg ^
  --empty calibration/empty.jpg ^
  --full calibration/full.jpg ^
  --output-dir banana_area_output
```

## 输出

```text
banana_area_output/
  before_mask.png
  after_mask.png
  before_overlay.jpg
  after_overlay.jpg
  result.json
```

重点人工检查：

- overlay 中黄色掩膜是否主要覆盖香蕉。
- 背景或黄色包装是否被大量选中。
- 放入、取出方向是否正确。
- 整理位置时是否错误跨越数量等级。

默认等级为：

| 占比 | 等级 |
|---|---|
| `< 10%` | 无 |
| `10% - 35%` | 少量 |
| `35% - 70%` | 适量 |
| `>= 70%` | 大量 |

使用空场景和满量校准图时，占比按校准范围计算；未提供校准图时，使用黄色掩膜占裁剪图面积的比例。

## 当前限制

- 当前颜色阈值主要适合黄色成熟香蕉。
- 青香蕉、阴影、低光照和黄色包装会影响结果。
- 前后裁剪区域必须尺寸一致。
- 必须先由 YOLO 或人工确认目标类别为香蕉，不能直接把所有黄色区域当成香蕉。
- 验证结果未达到稳定标准时，只能作为未来扩展方案写入报告。
