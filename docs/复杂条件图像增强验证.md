# 复杂条件图像增强离线验证

## 定位与边界

本工具使用轻量 OpenCV 方法，对低光、强高光及疑似反光覆盖场景进行离线演示验证。

- 不修改 `main.py`、YOLO 输入或库存主链路。
- 高光压制仅降低亮斑视觉强度，不能恢复被遮挡的真实纹理。
- `possible_reflective_cover` 仅表示启发式风险，不能确定存在塑料膜。
- 偏振去反光需要实体偏振镜，软件不能替代。

## 使用方法

```powershell
python tools/evaluate_complex_conditions.py `
  --input images/test.jpg `
  --output-dir complex_conditions_output
```

输出包括：

```text
original.jpg
low_light_enhanced.jpg
highlight_mask.png
highlight_suppressed.jpg
result.json
```

## 算法与指标

- 低光增强：平均亮度门限、自动 Gamma、轻度双边降噪、LAB-L 通道 CLAHE。
- 高光处理：HSV 相对高亮度、低饱和度掩膜，形态学处理后进行局部亮度压缩。
- 风险提示：综合高光面积比例、碎片数量及高光附近边缘密度。
- 指标：平均亮度、灰度标准差、动态范围、高光面积比例、碎片数量、风险分数。

## 实拍测试方案

分别采集正常光照、低光照、手电筒强高光、塑料膜覆盖、透明保鲜袋和反光包装袋场景。每类使用多张不同角度图片，检查输出图、指标波动、误检与漏检，不以单张成功图片代表整体效果。

## 论文建议表述

基于轻量 OpenCV 方法完成低光增强、高光区域检测与亮度压制的离线验证，具备端侧运行可行性；该方法尚未接入识别主链路，高光压制不能恢复过曝丢失的纹理，也不能证明已经解决所有低光、强反光和透明覆盖问题。偏振抑制反光仍需实体偏振镜配合。
